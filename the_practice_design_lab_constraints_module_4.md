# The Practice Design Lab: Constraints

## Module 4 — Choose One Constraint Lever

### Module Goal

By the end of this module, you should be able to choose one meaningful part of an activity to change.

This is where the constraint starts to take shape.

In Module 3, you identified what players need to notice earlier, more clearly, or differently.

Now the question becomes:

> What can I change in the activity so that information becomes harder to ignore?

That change is your constraint lever.

# Screen 2 — What Is a Constraint Lever?

A constraint lever is one part of the activity you can adjust.

You are not redesigning the entire practice.

You are changing one meaningful thing.

That one change might involve:

- Space
- Scoring
- Number of players
- Starting situation
- Rules
- Roles
- Pressure
- Opponent behavior

Each lever changes the problem in a different way.

The goal is not to use every lever.

The goal is to choose the lever that best matches your attention target.

## Key Idea

The constraint should serve the problem.

Do not change the activity just to make it different.

Change it to make the right information more useful, more visible, or more necessary.

# Screen 4 — The One-Lever Rule

When coaches first start using constraints, they often add too much.

A bonus point.

A new rule.

A smaller space.

A time limit.

A required action.

A special role.

All at once.

That usually creates confusion.

Players stop solving the sport problem and start trying to remember the coach’s instructions.

Start with one lever.

Run it.

Watch what changes.

Then adjust if needed.

## Key Idea

**One good constraint beats five clever ones.**

## Quick Check

Which version is usually better for a first attempt?

A. Change the scoring, space, roles, time limit, and contact rules all at once.  
B. Change one meaningful part of the activity and watch what happens.

**Correct answer:** B

## Feedback

B gives you a cleaner signal.

If the activity improves or breaks down, you can actually tell what changed.

# Screen 5 — Lever 1: Space

Change the space when players need to notice:

- Open space
- Crowding
- Support angles
- Defensive gaps
- Width
- Depth
- Distance
- Where pressure is coming from

Space constraints can include:

- Smaller area
- Larger area
- Wider area
- Narrower area
- Target zones
- Protected zones
- Bonus zones
- No-go zones
- Scoring areas
- Recovery spaces

## Example

**Problem:**  
Players crowd the ball when a teammate is under pressure.

**Attention target:**  
Open support space and useful angles.

**Possible space constraint:**  
The team earns a bonus point if the next successful action comes from a player who created or found space away from the crowded area.

## Best Use

Use space when the problem is about where players are, where they are not, or what areas they are failing to recognize.

---

# Screen 6 — Lever 2: Scoring

Change the scoring when players need to value a behavior, decision, or outcome differently.

Scoring constraints can include:

- Bonus points
- Double points
- Score only after a target behavior
- Must-win sequences
- Start at a pressure score
- Consequence scoring
- Streak scoring
- Response scoring

Scoring is powerful because it tells players:

> This matters.

## Example

**Problem:**  
Players keep choosing safe options that do not challenge the opponent.

**Attention target:**  
Opportunities to create pressure.

**Possible scoring constraint:**  
A team earns two points when an action creates clear pressure on the opponent, and one point for a normal score.

## Best Use

Use scoring when players understand the activity but need the game to reward a different behavior or decision.

---

# Screen 7 — Lever 3: Number of Players

Change the number of players when you want to change:

- Repetition
- Responsibility
- Space per player
- Decision load
- Communication demand
- Tactical complexity
- Time on the ball/object
- Off-ball involvement

Player-number constraints can include:

- 1v1
- 2v1
- 2v2
- 3v2
- 3v3
- 4v4
- Small-sided to full-sided progressions
- Overload or underload situations

## Example

**Problem:**  
Players are hiding off the ball and not supporting the action.

**Attention target:**  
When and where to become useful to a teammate.

**Possible number constraint:**  
Use a smaller-sided version of the activity so each player has fewer places to hide and more responsibility to support.

## Best Use

Use player numbers when the current activity gives players too little involvement, too much complexity, or not enough responsibility.

---

# Screen 8 — Lever 4: Starting Situation

Change the starting situation when the problem happens in a specific moment.

Starting situations can include:

- Start after a mistake
- Start from pressure
- Start from transition
- Start near a boundary
- Start with an advantage
- Start with a disadvantage
- Start from a specific game state
- Start with the opponent already organized
- Start with the opponent recovering

## Example

**Problem:**  
Players are slow to recover after losing possession.

**Attention target:**  
The moment possession changes and the next useful recovery space.

**Possible starting constraint:**  
Every round starts immediately after a turnover, and the team has three seconds to recover into useful defensive positions.

## Best Use

Use starting situations when you want players to rehearse recognizing and solving a specific game moment.

---

# Screen 9 — Lever 5: Rules

Change the rules when you want to limit, require, or shape player options.

Rule constraints can include:

- Must use a teammate before scoring
- Must attack within a certain time
- Cannot use the same option twice in a row
- Must change the point of attack
- Must use a certain number of passes or contacts
- Cannot enter a space too early
- Must recover before rejoining the attack
- Only certain actions count for scoring

Rules can focus attention, but they can also make practice weird if overused.

## Example

**Problem:**  
Players force the same option every time.

**Attention target:**  
Alternative options and opponent positioning.

**Possible rule constraint:**  
The team cannot score using the same final option twice in a row.

## Best Use

Use rules when the activity needs a boundary that nudges players away from habits and toward exploration.

---

# Screen 10 — Lever 6: Roles

Change roles when players need a clearer responsibility inside the activity.

Role constraints can include:

- One player must provide support information
- One player starts as the recovery player
- One player is responsible for creating width
- One player must organize the defensive shape
- One player starts under pressure
- One player begins as the target player
- One player must scan and communicate before acting

## Example

**Problem:**  
Players are not giving useful information to teammates before they act.

**Attention target:**  
A teammate’s situation and what information would help.

**Possible role constraint:**  
One player is assigned as the “information player” and earns the team a bonus point when their early cue helps a teammate make a better decision.

## Best Use

Use roles when players need to understand responsibility, support, communication, or coordination.

---

# Screen 11 — Lever 7: Pressure

Change pressure when players can solve the problem in easy conditions but lose it when the challenge rises.

Pressure constraints can include:

- Time limit
- Score pressure
- One-ball challenge
- Must score twice in a row
- Start at a late-game score
- Opponent gets a bonus for mistakes
- Next action after error is worth more
- Limited opportunities to solve the problem

## Example

**Problem:**  
Players make good choices in low-pressure practice but rush when the score is close.

**Attention target:**  
Available options under pressure.

**Possible pressure constraint:**  
Start each round at a close score and require the team to win two pressure points before rotating.

## Best Use

Use pressure when the problem is not whether players can do something, but whether they can still do it when the moment matters.

---

# Screen 12 — Lever 8: Opponent Behavior

Change opponent behavior when you want players to read a specific problem.

Opponent constraints can include:

- Opponent must apply pressure in a certain area
- Opponent starts in a certain shape
- Opponent can only defend certain spaces
- Opponent is encouraged to exploit a weakness
- Opponent must change behavior after each round
- Opponent creates a predictable problem at first, then becomes less predictable

## Example

**Problem:**  
Players are not recognizing when the opponent leaves space open.

**Attention target:**  
Opponent position and available space.

**Possible opponent constraint:**  
The defense starts by overloading one side, creating open space elsewhere. The attacking team must identify and use the space.

## Best Use

Use opponent behavior when players need to learn to read an actual opponent, not just execute a pattern.

# Screen 19 — Do Not Add the Constraint Yet

You have chosen the lever.

But we are not finished.

Choosing the lever is not the same as writing the constraint.

For example:

## Lever

Scoring

## Constraint

The team earns a bonus point when early, useful communication helps a teammate make a better decision.

## Lever

Space

## Constraint

A player must create or find open support space before the team can score.

## Lever

Pressure

## Constraint

Start each round at a close score, and the team must solve the same problem under game-like pressure.

The lever is the category.

The constraint is the actual change.

In the next module, you will turn the lever into a specific activity upgrade.

# Screen 20 — Common Lever Mistakes

## Mistake 1: Choosing the Most Creative Lever

Creativity is not the goal.

Use the lever that best fits the problem.

## Mistake 2: Choosing Too Many Levers

Start with one.

You can always adjust later.

## Mistake 3: Choosing a Lever That Does Not Match the Attention Target

If you want players to notice space, but your constraint only changes punishment, the lever probably does not match the problem.

## Mistake 4: Making the Activity Unrecognizable

The activity should still feel connected to the sport.

## Mistake 5: Confusing Difficulty With Usefulness

Harder is not automatically better.

A useful constraint makes the problem clearer.

# Screen 21 — Multi-Sport Examples

Use these examples as models.

## Basketball

**Problem:**  
Off-ball players crowd the ball when the ball handler is pressured.

**Attention target:**  
Open support angles.

**Best lever:**  
Space

**Why:**  
The problem is about where support is being created or lost.

---

## Soccer

**Problem:**  
Players force the ball down the line near the sideline, trapping the next teammate.

**Attention target:**  
Pressure, central support, and safer options.

**Best lever:**  
Opponent behavior or space

**Why:**  
The coach may shape opponent pressure near the sideline or create value for switching away from pressure.

---

## Volleyball

**Problem:**  
Players send the ball over with no plan.

**Attention target:**  
Open space and defender position.

**Best lever:**  
Scoring or opponent behavior

**Why:**  
Scoring can reward intentional placement, or opponent positioning can create a clearer reading problem.

---

## Hockey

**Problem:**  
Players hold the puck too long under pressure.

**Attention target:**  
Early support options.

**Best lever:**  
Pressure or number of players

**Why:**  
The coach can preserve pressure while creating more frequent chances to recognize and use support.

---

## Flag Football

**Problem:**  
Receivers run into the same space.

**Attention target:**  
Spacing, timing, and route relationship.

**Best lever:**  
Space or roles

**Why:**  
The coach can shape where players are allowed to start, finish, or create separation.

# Screen 23 — Lever Selection Self-Check

Before moving on, check your lever choice.

Can you answer yes to these?

1. Does this lever connect to my clear practice problem?
2. Does this lever connect to my attention target?
3. Can I change this lever without making the activity unrecognizable?
4. Can I explain the change quickly?
5. Will this lever help players notice something useful?
6. Does this lever avoid unnecessary complexity?
7. Can I watch the activity and see whether it helped?

If you have at least five yes answers, you are ready to move on.

If not, choose a simpler or better-matched lever.

## Revision Prompt

If your lever does not fit, return to this sentence:

> I want players to notice __________ when __________ so they can __________.

Then ask:

> Which lever would make that information matter?
