# The Practice Design Lab: Constraints

## What Comes After Module 6?

After Module 6, the **core course is complete**.

Do not add another teaching module unless it has a clear job.

Module 6 already ends with the full course artifact:

# Activity Upgrade Plan

By this point, the learner should have:

- An existing activity
- A clear practice problem
- An attention target
- A constraint lever
- A specific constraint
- A success condition
- A coaching question
- An adjustment plan

The course has done its job if the coach can now walk into practice tomorrow and test one meaningful activity upgrade.

---

# Recommended Post-Course Structure

Instead of adding a Module 7, add a short **course wrap-up and implementation section**.

# 2. Tomorrow Challenge

## Purpose

Move the learner from course completion to practice action.

The goal is not just to finish the course.

The goal is to use the activity upgrade.

## Screen Title

**The Tomorrow Challenge**

## Learner-Facing Text

Run this activity at your next practice.

Do not wait until the plan feels perfect.

Use the first version.

Watch what changes.

Make one adjustment.

That is the work.

## Challenge Instructions

At your next practice:

1. Run the activity you upgraded.
2. Explain the constraint simply.
3. Watch the attention target.
4. Ask your coaching question.
5. Notice which signal appears:
   - Too easy
   - Too hard
   - Too weird
   - Nothing changes
6. Make one adjustment.
7. Write one short reflection after practice.

# 3. Bonus Resource Library

---

## Bonus Resource 1 — Constraint Lever Cheat Sheet

### Purpose

Help coaches quickly choose a lever.

### Content

## Space

Use when players need to notice:

- Open space
- Crowding
- Support angles
- Defensive gaps
- Width
- Depth

Common changes:

- Smaller area
- Larger area
- Target zones
- Bonus zones
- No-go zones
- Recovery spaces

## Scoring

Use when players need to value a behavior or decision differently.

Common changes:

- Bonus points
- Double points
- Score only after target behavior
- Must-win sequences
- Pressure score
- Response scoring

## Number of Players

Use when players need more involvement, touches, decisions, or responsibility.

Common changes:

- 1v1
- 2v1
- 2v2
- 3v2
- 3v3
- 4v4
- Small-sided to full-sided progressions

## Starting Situation

Use when the problem happens in a specific game moment.

Common changes:

- Start after a mistake
- Start from pressure
- Start in transition
- Start near a boundary
- Start with advantage/disadvantage
- Start from a specific score or game state

## Rules

Use when players need their options shaped.

Common changes:

- Must use a teammate
- Cannot repeat the same option
- Must change point of attack
- Must act within a time window
- Certain actions count for scoring

## Roles

Use when players need clearer responsibility.

Common changes:

- Information player
- Support player
- Recovery player
- Target player
- Organizer
- Pressure player

## Pressure

Use when players can solve the problem in easy conditions but lose it when the challenge rises.

Common changes:

- Time limit
- Score pressure
- One-ball challenge
- Start at close score
- Must score two in a row
- Error response scoring

## Opponent Behavior

Use when players need to read a specific opponent-created problem.

Common changes:

- Opponent starts in a shape
- Opponent overloads one side
- Opponent pressures a specific area
- Opponent leaves a space open
- Opponent changes behavior between rounds

## Bonus Resource 3 — Troubleshooting Guide

### Purpose

Help coaches adjust without panicking.

## If It Is Too Easy

Try:

- Add pressure
- Add opponent complexity
- Increase space
- Reduce time
- Reduce the bonus
- Require the behavior in a harder situation
- Move closer to the full game

## If It Is Too Hard

Try:

- Reduce pressure
- Make the space smaller or simpler
- Slow the starting situation
- Use fewer players
- Make the opponent more predictable
- Clarify what counts
- Remove extra rules

## If It Gets Weird

Try:

- Remove artificial rules
- Use more normal scoring
- Add a real opponent problem
- Make the success condition game-relevant
- Ask whether the activity still teaches the target problem

## If Nothing Changes

Try:

- Revisit the problem statement
- Clarify the attention target
- Strengthen the reward
- Change the lever
- Change the starting situation
- Make the success condition more visible
- Ask players what they noticed

## Bonus Resource 4 — Multi-Sport Example Bank

### Purpose

Help the course speak beyond one sport.

## Example 1 — Basketball

### Problem

Off-ball players crowd the ball when the ball handler is pressured.

### Attention Target

Open support angles.

### Possible Constraint

The team earns a bonus point when an off-ball player creates a useful passing lane before the ball handler gets trapped.

### Coaching Question

Where could you become useful before your teammate ran out of options?

---

## Example 2 — Soccer

### Problem

Players force the ball down the line near the sideline, trapping the next teammate.

### Attention Target

Pressure, central support, and safer options.

### Possible Constraint

The team earns a bonus point when they recognize sideline pressure and use a central or backward support option to escape.

### Coaching Question

What did the pressure take away, and what did that open?

---

## Example 3 — Volleyball

### Problem

Players send the ball over with no plan.

### Attention Target

Open space and defender position.

### Possible Constraint

The team earns a bonus point when the ball is sent intentionally to open space.

### Coaching Question

What did you see before you sent the ball over?

---

## Example 4 — Hockey

### Problem

Players hold the puck too long under pressure.

### Attention Target

Early support options.

### Possible Constraint

The team earns a bonus point when a player moves the puck out of pressure to an available support option before being trapped.

### Coaching Question

What option was available before the pressure closed?

---

## Example 5 — Lacrosse

### Problem

Players drive into help defense without reading whether the adjacent defender has committed.

### Attention Target

Help defender position and teammate availability.

### Possible Constraint

The offense earns a bonus point when the ball carrier draws help and moves the ball to the open teammate.

### Coaching Question

What did the help defender give you?

---

## Example 6 — Flag Football

### Problem

Receivers run into the same space.

### Attention Target

Spacing, timing, and route relationship.

### Possible Constraint

The offense earns a bonus point when a completed pass comes from two receivers creating different useful spaces.

### Coaching Question

How did your route create space for yourself or a teammate?
